# 流程圖動畫工具

不需安裝套件即可使用的流程圖動畫編輯器。

## 開啟方式

直接開啟 `index.html` 即可使用主要編輯功能。若需要 MOV 或 MP4 輸出，再另外執行 `start.ps1` 啟動本機轉換服務。

按下「新專案」會清除節點、連接線、來源文字與背景，建立完全乾淨的工作區。請使用上方「匯入文字」選擇 `.txt` 檔案；工具會自動解析，不需貼上文字或手動按解析。

## 文字格式

```text
1.讀取 SpaceMouse 六軸
2.確認游標所在區域
3.畫布區
	3.1優先允許 Z：縮放畫布
4.時間軸區
	4.1優先允許 rx / ry / rz
```

- 整數節點依序連線。
- 小數編號節點連到對應父節點。
- 子節點階層必須使用 `Tab`，不可使用空白。

## 功能

- 匯入文字、自動產生節點與連接線、自動排版。
- 匯入時依節點文字長度自動調整色塊尺寸，並依編號層級分欄、在畫布中平均分散。
- 節點拖曳、多選、刪除、樣式範本與細部樣式。
- 畫布空白處拖曳維持框選；滑鼠中鍵拖曳可上下左右平移畫布。滑鼠滾輪會以游標位置為中心縮放。
- 選取節點時，`Shift` 點擊可跳著加選；框選可一次選取連續範圍；`Ctrl` 點擊或框選可從目前選取範圍減選。
- 左側工具區、右側屬性區與下方時間軸可拖曳分隔條調整尺寸，設定會自動保存。
- 連接線預設無箭頭；按下「新增連接線」後，可依序點擊來源與目標節點，也可直接從來源拖拉至目標節點。來源節點會高亮提示，模式可連續建立線條。
- 連接線支援直線、曲線、多個控制點、端點換接節點、錨點拖曳、實線、虛線、正反向箭頭及多種端點造型。
- 時間軸播放頭固定在中央，片段會依目前時間左右移動；可使用工具列或鍵盤 `←`、`→` 以 `0.1` 秒微調。
- 時間軸採圖層列操作：點擊左側圖層列選取，`Ctrl` 可多選，拖曳圖層列可調整上下順序；垂直捲動時播放頭仍固定顯示。
- 時間軸片段可拖曳調整開始時間，左右邊緣可拖曳調整動畫時長。空白處框選多個片段後，可整組向左右移動。
- 匯入文字後，時間軸預設依「節點 → 對應線條 → 下一個節點」交錯排列；仍可拖曳標籤手動排序。
- 時間軸軌道標籤可上下拖曳調整顯示順序；點擊節點片段時，左側同層級節點會反白，畫布會捲動至該節點。
- 時間軸提供可拖曳播放頭，也可點擊軌道空白位置逐格預覽。
- 拉高時間軸時，畫布會依可用空間自動縮小，畫布區仍可上下捲動查看。
- 節點與連接線提供多種動畫效果及線性、加速、減速、先加速後減速、彈性、回彈速度曲線。
- 多選節點後可使用靠左、置中、靠右、靠上、置中、靠下、水平及垂直均分。
- 節點字型可從 Windows 已安裝字型清單選擇。
- 節點支援膠囊、圓角矩形、矩形、圓形、橢圓形，以及漸層、純色或無底色。外框可設為純色、漸層或無外框。
- 節點尺寸、圓角、線條粗細與箭頭尺寸可用滑桿即時預覽。
- 自動保存、專案匯入與匯出。另提供「儲存版面／載入版面」快速保存目前節點、線條、畫布與時間軸排序。
- 純色、漸層、圖片與透明畫布。
- 背景圖片可移除；透明畫布使用棋盤格提示，透明格不會寫入輸出。
- 影片與透明 PNG 影格序列 ZIP 輸出，避免瀏覽器阻擋連續多檔下載。

## 驗證解析器

已安裝 Node.js 時，可以執行：

```powershell
node .\test-parser.js
```

## 影片格式

輸出前可勾選「透明背景」。勾選後畫布會直接變透明；取消勾選後會回到原本的純色、漸層或圖片背景。

- 「輸出 MOV」：透明背景會建立 ProRes 4444 MOV；非透明背景會建立 ProRes 422 MOV。
- 「輸出序列」：透明背景會建立透明 PNG 序列 ZIP；非透明背景會建立含背景 PNG 序列 ZIP。
- 「輸出 MP4」：非透明背景會建立 H.264 MP4。透明背景時會改建立 WebM VP9 alpha，因為標準 H.264 MP4 不可靠支援透明通道。

輸出時會使用乾淨渲染層，不包含選取框、錨點、控制點或編輯輔助線。MOV 與 MP4 需要以 `start.ps1` 啟動本機 FFmpeg 轉檔服務。
